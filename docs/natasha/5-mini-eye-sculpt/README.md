# Natasha Denona 5色 迷你塑眼盘 Mini Eye Sculpt Palette

专为眼妆塑形设计，提供 Neutral（中性）与 Cool（冷调）两款配色，各含 5 个由浅至深全哑光色号，从极浅高光至极深黑色，覆盖所有肤色的打底、眼窝过渡和眼尾定型。结合轻盈 Silky Matte（亮肤浅色）与经典 Creamy Matte（中深色）双配方，哑光发色饱满，无缝晕染，单颗 0.8g。
